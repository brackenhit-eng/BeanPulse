# BeanPulse Static Website

Professional static artist website for BeanPulse.

## Files

- `index.html`
- `style.css`
- `script.js`
- `assets/`

## Free Hosting

This site has no backend, no database, and no build step. Upload the full folder to:

- GitHub Pages
- Netlify
- Vercel

For Netlify, drag the folder into `https://app.netlify.com/drop`.

## Customize

- Change music/social links in `index.html`.
- Replace placeholder TikTok, Facebook, Instagram, Apple Music, and TikTok release links.
- Replace the video placeholder in the `Latest Video` section with a real YouTube embed or video link.
- Update artwork by replacing files inside `assets/` while keeping the same filenames.
